##   Organiser le processus de développement

| **Étape**      | l'objectif et livrable                                                                                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **cadrer**     | understanding how to add an category and manupilate the other proccesses like delete update and show                                                                                 |
| **Concevoir**  | start structure define the table category(id-name-color...), and creating an api structure + know whats gonna be in the form                                                         |
| **Développer** | Create the page which is an   html form with prevalidation + a show table to show all the categories + all the CRUD operations for the API (post+ put+delete+get) + create table sql |
| **Tester**     | check if all the functions works as expected( the show , the add , the delete and the modify ) + list all the error u got or 0 if not any                                            |
| **Valider**    | verify the functionality if its as expected and there is no change outside the plan                                                                                                  |
